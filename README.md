# LayoutDropper

一个原生 macOS 菜单栏窗口布局工具，支持可配置的拖动触发、分屏与调试区域。

## 功能

- 普通拖动窗口到屏幕边缘即可预览分屏，无需按任何快捷键；松开鼠标后应用，离开边缘则取消预览
- 从窗口顶部拖动至少 18pt，且窗口实际发生移动；默认边缘条厚度为 8pt，可分别自定义七个边角区域的宽高
- 四个角：窗口放到对应的四分之一屏幕区域
- 左右边缘中点：窗口放到左半屏或右半屏
- 顶部中点：窗口铺满当前屏幕可用区域（保留菜单栏和 Dock，不进入独立全屏空间）
- 按住 Shift 拖动时显示原来的左上角 1920×1080“1080P 调试”遮罩；屏幕可用区域不足时自动缩小
- 边角分屏优先于调试遮罩，普通拖动不会显示或触发调试遮罩
- 多屏时使用鼠标所在屏幕的布局
- 松开调试触发键取消调试遮罩，不影响无快捷键的边缘分屏；按 Escape 取消本次布局
- 菜单栏可快速启用/暂停、打开设置、重新连接监听和查看版本

## 设置

点击菜单栏图标 -> “设置…”，首次运行会自动打开设置窗口。配置即时保存，重新启动后保留。

- **通用**：启用/暂停、登录启动、调试遮罩触发键（Shift / Option / Control / Control + Option）、拖动距离、窗口顶部范围和遮罩透明度。
- **布局**：八个布局区域分别启用/关闭，调试区域宽高可自定义；尺寸按 macOS 逻辑点（pt）计算。
- **触发区域**：四角、左侧、右侧和顶部七个区域的宽高分别设置，输入框与步进器即时保存，示意图实时刷新。比如顶部 `1200×12`、左侧 `12×800`、右侧 `12×800`，可形成细长边缘条。
- **权限**：辅助功能、输入监控和事件监听状态，以及授权、系统设置和重新连接入口。
- 窗口底部提供恢复默认设置与关于入口。恢复默认保留系统登录启动设置。

实际分屏和触发区域按鼠标所在屏幕的 `NSScreen.frame` / `visibleFrame` 计算，分屏避开菜单栏与 Dock，不以 1080P 为基准。设置示意图读取设置窗口所在屏幕的真实尺寸，切换屏幕或更改显示设置时刷新；窗口顶部显示屏幕名称、逻辑尺寸（pt）及当前显示模式像素（px）。Retina / 缩放模式下使用逻辑点布局，像素尺寸不直接作为窗口坐标。只有用户保留的调试遮罩默认是 `1920×1080 pt`，可在布局页单独修改。

边缘分屏始终要求窗口实际移动，文本拖选不会触发。调试遮罩默认也要求窗口实际移动，可单独在设置中调整。

自定义触发区域固定贴在对应屏幕边缘，顶部和左右区域分别沿边居中；宽度和高度同时决定实际命中范围。尺寸自动限制在当前屏幕内，不改变分屏后的窗口尺寸或调试遮罩尺寸。区域重叠时四角优先。升级保留旧设置和边缘触发行为，修改后的区域按新的宽高命中。

## 使用

1. 运行 `bash build_release.sh --pkg`，生成 `build/LayoutDropper.app`、`build/LayoutDropper.zip` 和 `build/LayoutDropper-1.4-macos-universal.pkg`。
2. 将 App 放入 `/Applications`，退出旧版后启动新版。
3. 在设置的“权限”页申请辅助功能授权；监听仍无法启动时，打开输入监控设置授权。
4. 在“通用”和“布局”页调整配置，需要时开启登录启动。

开发时也可以用 Xcode 打开 `LayoutDropper.xcodeproj`，选择 `LayoutDropper` / `My Mac` 后运行。

建议最终把 Release 版复制到 `/Applications/LayoutDropper.app` 后再授权，避免 Xcode DerivedData 临时路径导致权限错乱。

安装包将程序固定安装到 `/Applications/LayoutDropper.app`。升级前先退出旧程序，安装后重新启动；覆盖文件不会替换仍在运行的旧进程。安装包未签名、公证，App 使用本机 ad-hoc 签名。

## 验证

覆盖横屏、竖屏、副屏偏移、奇数尺寸和小屏幕布局，以及配置保存、范围校验、组合键匹配、设置控件联动和窗口重开：

```sh
bash verify.sh
```

设置窗口测试使用临时配置，不修改现有设置或登录启动。设置界面截图检查可通过 `LAYOUTDROPPER_SCREENSHOTS=/tmp/LayoutDropperQA bash verify.sh` 开启。

## 隐私与兼容性

- macOS 13 或更高版本，Release 包包含 Intel 与 Apple Silicon 架构。
- 配置保存在当前用户的本机偏好设置中，无网络请求和遥测。
- 全局事件只监听，不拦截其他应用输入；暂停后停止监听。
- 部分应用有最小窗口尺寸限制，实际分屏尺寸可能受其限制。
